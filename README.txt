ব্যক্তিগত রিপোর্ট বই — সংশোধিত অফলাইন সংস্করণ

GitHub Pages রিপোজিটরিতে index.html, manifest.json, sw.js, icon.svg চারটি ফাইল একই মূল ফোল্ডারে আপলোড করুন। index.html-এর Supabase সেটিংস আপনার প্রকল্পের সঙ্গে মিলে আছে।

এই সংস্করণে loadReports ফাংশনের অনুপস্থিতি ঠিক করা হয়েছে। আপলোডের পরে Chrome-এ সাইট খুলে রিফ্রেশ করুন। পুরোনো ইনস্টল/ক্যাশ থাকলে Chrome Site settings থেকে শুধু এই সাইটের cache/site data clear করে আবার খুলতে হতে পারে; তবে আগে নিশ্চিত করুন গুরুত্বপূর্ণ অফলাইন রিপোর্ট সিঙ্ক হয়েছে।
